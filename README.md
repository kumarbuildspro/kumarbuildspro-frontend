# 🚀 KumarBuildsPro - Portfolio & Services Website

A modern, responsive, and high-performance full-stack web application designed to showcase professional web development services and portfolio projects. Built with a sleek glassmorphic UI, dynamic canvas animations, and integrated with a RESTful API and database for seamless contact form submissions.

---

## 🌟 Live Demo

- **Frontend Application:** [https://kumarbuildspro-frontend.onrender.com/](https://kumarbuildspro-frontend.onrender.com/)
- **Backend API:** [https://kumarbuildspro-backend.onrender.com](https://kumarbuildspro-backend.onrender.com)

---

## ✨ Features

- 🎨 **Modern Glassmorphic UI:** Clean, dark-themed user interface with glassmorphism effects.
- 🌌 **Interactive HTML5 Canvas:** Dynamic interactive background particle system responding to user mouse movements.
- 📱 **Fully Responsive:** Smooth design optimized across Mobile, Tablet, and Desktop screens.
- 📬 **Live Contact Form Integration:** Submits user inquiries directly to the backend API and stores them securely in a MongoDB cloud database.
- 🚀 **Cloud Deployed:** Automated continuous integration and deployment (CI/CD) hosted via Render.

---

## 🛠️ Tech Stack

### Frontend
- **HTML5 & CSS3:** Semantic layout and modern responsive styling.
- **JavaScript (ES6+):** Asynchronous API communication using `fetch`, DOM manipulation, and HTML5 Canvas logic.
- **Font Awesome:** Scalable vector icons.

### Backend
- **Node.js & Express.js:** Scalable RESTful API server.
- **MongoDB Atlas:** Cloud NoSQL database for contact form submission storage.
- **Mongoose:** Object Data Modeling (ODM) library for MongoDB.
- **CORS:** Cross-Origin Resource Sharing configured for secure frontend-backend communication.
